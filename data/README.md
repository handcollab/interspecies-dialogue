# 三界共語 Interspecies Dialogue・植物端資料

研究團隊在 2025-12-10 到 2026-02-11 之間，用顯微鏡錄下葉片表皮的氣孔（stomata）開與關，前後經過數百次測試；這裡收錄的是其中精選節錄的 200 段。這個資料夾是把這 200 段的試算表紀錄整理成網站可以直接讀的格式。

所有檔案都已去識別化：不含人員姓名、帳號、雲端連結或任何識別碼；原表中標註者的署名已刪除。提到人時只用「研究團隊」。

## 檔案

| 檔案 | 內容 |
| --- | --- |
| `experiments.json` | 精選 200 段錄影的實驗條件與結果（陣列，每段一筆） |
| `experiments.csv` | 同上的精簡表格，UTF-8（含 BOM，Excel 可直接開） |
| `annotations.csv` | 55 段標註的表格：前 14 欄是原表欄位（標註素材之編號 … 備註），後 5 欄是整理後的結果分類、是否計入、標註格式、開口曲線與最大開口 |
| `annotations.json`（原名 yolo.json） | 其中 55 段的氣孔開度標註（陣列），供自動辨識使用 |

## experiments.json 欄位

| 欄位 | 說明 |
| --- | --- |
| `id` | 1–200，等於原試算表列號減 1（`sheet_row` 為原列號） |
| `date` | 錄影日期（ISO） |
| `plant_zh` / `plant_en` | 鴨拓草 Inchplant（紀錄影片〈實驗〉稱紫背鴨跖草）、紫錦草 Purple heart、扶桑花 Chinese hibiscus、佛羅里達蔓綠絨 Philodendron 'Florida'。沿用中文俗名，英文與學名是推定，未經鑑定 |
| `scope` / `handheld` | `MICROTECH`（12 月至 1 月）或 `Dino-Lite`（2 月起的手持顯微鏡） |
| `mag` / `mag_approx` | 放大倍率；手持機的倍率是約值（`mag_approx: true`） |
| `variable` | 原表的實驗變因：`水` 或 `光照` |
| `method` / `method_en` | 噴水、刷毛、浸泡、浸泡 5 秒、浸泡 5 秒 + 刷毛、藍光、白光、手機手電筒 |
| `stimulus` | 統計用的粗分組：`水`、`藍光`、`其他光`（白光、手機手電筒） |
| `humidity` / `temp` | 濕度 %、溫度 °C；最早 3 段沒有紀錄（`null`） |
| `light` | 原表「光照」欄，200 段都是 450 nm / 660 nm，推測是錄影環境的固定照明規格；實驗變因的「藍光」是另外加照的藍光手電筒 |

| `outcome` / `outcome_en` | 結果分類，規則見下 |

| `watered_ago_hours` | 距上次澆水的時數：剛澆完水 = 0、約一週 = 168、「約 X 天」= X × 24；沒寫就是 `null` |
| `watered_ago_text` | 判讀用的原文片語 |
| `flags` | 從備註抽出的標記：更換電池、藍光電力微弱、藍光電力下降、藍光中途沒電、藍色玻璃紙照明、新葉、蟲害、自然斷枝、前一日剪下、錄影檔毀損、溫濕度未記錄、疑似氣體排出、植株狀況不佳、葉片綠化、正常葉片、實驗前可能已開、部分氣孔已微開 |
| `yolo_id` | 有開度標註的話，對應 `annotations.json` 的 `id` |

## 結果分類規則

分類用的是研究團隊自己的說法（備註文字），沒有重新看影片判讀。依序比對，先符合者為準：

| 規則 | 備註中出現 | 分類 | 可信度 |
| --- | --- | --- | --- |
| R1 | 「有待商榷」 | 待商榷 | 高 |
| R2 | 「難以觀測」 | 難以觀測 | 高 |
| R3 | 「效果顯著」「開關緩慢但顯著」等含「顯著」 | 顯著 | 高 |
| R4 | 「開關不明顯」「開關緩慢不明顯」 | 不明顯 | 高 |
| R5 | 「無明顯開關」 | 無明顯 | 高 |
| R6 | 只寫「開關緩慢」或「些微打開」 | 不明顯（保守歸類） | 低 |
| R7 | 備註整格空白 | 未記錄 | — |
| R8 | 備註有字，但沒寫開關結果 | 明顯(空白) | 中 |

R8 依據研究團隊的慣例：備註沒寫結果，代表「開關明顯，但沒有到驚豔」，團隊稱為「空白」。R7 的 2 段（id 8、17）整格沒填，無法確定是否也適用這個慣例；其中 id 17 的開度標註顯示從 0% 開到約 40%。

## annotations.json 欄位

| 欄位 | 說明 |
| --- | --- |
| `id` / `exp_id` | 標註編號 1–55；對應的實驗 `id` |
| `counted` / `skip_reason` | 第 34、52 段沒有開度百分比，研究團隊未計入 |
| `format` | `points`：逐點標註「開度 / 時間」（主要是第 1–32 段）；`segments`：區段式標註（第 33 段起，或混用區段的列）；`none`：沒有開度 |
| `target` | 追蹤的是畫面中哪一顆氣孔（例：左上的氣孔） |
| `aperture` | `[[秒, 開度%], …]`，已依時間排序，可直接畫成曲線 |
| `aperture_interpolated` | `true` 表示有「20% - 30% - 40%」這種多段變化，中間值在區段內平均分配時間，只是示意 |
| `aperture_ambiguous` | `true` 表示標註寫成「0% / 30%」這種同時列多顆氣孔的形式；曲線取開最大的那一顆，因此可能出現跳動 |
| `segments` | 區段式標註的原始結構：`start`、`end`、`label`（原文）、`from`/`to`（起訖開度）、`lo`/`hi`（該段所有數值的範圍）、`ranges`、`other_stomata`（標註說是其他氣孔時為 `true`，不放進主曲線） |
| `good_segments` | 第 33 段起標註為畫質不錯的區間 `[[起, 迄], …]`（秒） |
| `noise` | 模糊、位置微調等雜訊區間 `[[起, 迄], …]`（秒）；第 13 段起研究團隊註明雜訊「非細緻標註」（`noise_coarse`） |
| `blurry` | 標註中提到偏模糊 |
| `duration_s_est` | 標註中出現的最大時間，約等於影片長度 |
| `metrics` | 由 `aperture` 算出：起始開度、最大開度與時間、漲幅、第一次比起始多 10 個百分點的時間（`t_rise10`）、峰值後回落幅度 |
| `annotation_notes` / `raw_aperture` / `raw_noise` / `parse_issues` | 標註上的文字說明、原始字串、解析時遇到的問題 |

解析時處理過的狀況：時間格式 m:ss 與 h:mm:ss、全形括號與標點、「40 ~ 60%」（視為數值範圍）、「a - b - c - d」多一個連字號（拆成兩個區間）、終點早於起點的區間（捨棄並記在 `parse_issues`）、時間倒退（輸出時重新排序並記錄）。全部 55 段都能解析，有 4 段留有 `parse_issues`。



## 使用限制

- 這 200 段是數百次測試中的精選節錄，不是全部測試；各種段數與比例只代表這 200 段。
- 這是觀察紀錄，不是對照實驗。日期、植株、葉片、顯微鏡、照明電力與澆水間隔彼此混雜，看到的差異不能當成因果。
- 樣本小且不平均：紫錦草 110 段、鴨拓草 63 段、扶桑花 26 段、佛羅里達蔓綠絨 1 段。
- 結果分類是研究團隊的目測判斷；開度百分比也是標註者目測估計，不是影像量測。
- 澆水間隔大多是「約 X 天」的約略值。
- YOLO 標註的 55 段是挑選過的素材，偏向看得到開關的片段。
